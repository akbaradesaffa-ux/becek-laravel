# Fitur Terdekat

- Menambahkan kolom `latitude` dan `longitude` pada `tb_lokasi`.
- Menambahkan halaman `/terdekat` untuk pengguna terautentikasi.
- Menambahkan filter radius 1, 3, 5, 10, dan 25 km.
- Menambahkan filter kategori Cafe/Warkop.
- Mengurutkan hasil berdasarkan jarak terdekat menggunakan rumus Haversine.
- Menambahkan tombol rute Google Maps tanpa API key.
- Menambahkan input koordinat dan ekstraksi koordinat dari link Google Maps lengkap pada panel admin.
- Menambahkan indikator lokasi yang sudah siap digunakan oleh fitur terdekat.
- Menambahkan test fitur untuk autentikasi, urutan jarak, radius, dan kategori.
